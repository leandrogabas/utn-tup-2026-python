# TP1 - API REST con FastAPI: ABM de Usuarios y Productos

Repositorio del **Trabajo Práctico 1** de la materia **Programación 4** (Tecnicatura Universitaria en Programación - UTN).

El código fuente del proyecto se encuentra en el directorio [`clase-fastapi`](./clase-fastapi).

## Inicio Rápido

```bash
cd clase-fastapi
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1 | Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
fastapi dev main.py
```

Una vez iniciado el servidor, acceder a la documentación interactiva **Swagger UI** en:
- **[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**

Consultá el [README completo en `clase-fastapi/README.md`](./clase-fastapi/README.md) para el detalle de la arquitectura y la tabla de endpoints.
